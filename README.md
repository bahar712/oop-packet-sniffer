# OOP Packet Sniffer & Traffic Analyzer

## Türkçe
Bu proje bir ağ trafiği izleme ve analiz aracıdır.
OOP prensipleriyle python ve scapy kullanılarak yazılmıştır.
Network ve OOP öğrenmek için yaptığım bir projedir.

## Özellikler

- Canlı ağ trafiği yakalar.
- IP adreslerini ayrıştırır.
- TCP/UDP protokolünü tespit eder.
- İstatistik çıkarır. (en çok trafik üreten IP'ler, protokol dağılımı gibi)

---

## English
This project is a network traffic monitoring and analysis tool.
It is written in Python using scapy, following OOP principles.
I built this project to learn networking fundamentals and object-oriented programming.

## Features

- Captures live network traffic
- Parses IP addresses from packets
- Detects TCP/UDP protocols
- Generates statistics (top talkers, protocol distribution)
